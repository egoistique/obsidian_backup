# Префиксные суммы
## Максимальная сумма подотрезка

Получаем

```
pref[r] - pref[l]
```

Для каждого `r` нужно максимизировать выражение.

Значит нужно минимизировать

```
pref[l]
```

Получается

```
храним минимальный префикс
```

---

Запоминается как

> **максимум разности ⇒ минимум первого элемента**

---

## 3. Найти количество отрезков с суммой K

Из

```
pref[r] - pref[l] = K
```

получаем

```
pref[l] = pref[r] - K
```

То есть нужно узнать

> сколько раз раньше встречался префикс

```
pref[r] - K
```

Получается

```
Dictionary<префикс, количество>
```

---

Запоминается как

> **нужно точное значение ⇒ словарь**


## 4. Существует ли такой отрезок?

Практически то же самое.

Но вместо количества

```
Dictionary<long, bool>
```

или

```
HashSet<long>
```

---

Запоминается как

> **нужно только узнать факт ⇒ HashSet**


# Получается очень красивая таблица

|Что нужно найти|Что хранить|
|---|---|
|Сумму одного отрезка|Ничего после построения префиксов|
|Максимальную сумму|Минимальный префикс|
|Минимальную сумму|Максимальный префикс|
|Есть ли сумма K|HashSet префиксов|
|Сколько сумм K|Dictionary<префикс, количество>|
|Минимальная длина|Dictionary<префикс, первый индекс>|
|Максимальная длина|Обычно тоже первый индекс|

## Скользящее окно, два указателя
| Тип задачи                                                         | Типичный шаблон                                          |
| ------------------------------------------------------------------ | -------------------------------------------------------- |
| Быстро считать сумму любого отрезка                                | Префиксные суммы                                         |
| Формула через `pref[r]-pref[l]`                                    | Префиксы + хранение минимума/максимума/другой статистики |
| Два отсортированных массива                                        | Два указателя (`двигаем либо L, либо R`)                 |
| Один массив, ищем лучший подотрезок с ограничением                 | Скользящее окно                                          |
| Для каждого нового элемента можно локально обновить состояние окна | Скользящее окно                                          |
